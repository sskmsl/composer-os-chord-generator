# ドラマティック・マイナー Phase 1(規則の実装)

Phase 0(`9a61ae7`)の続き。ブランチ `feat/dramatic-minor-rules`、PR #39。規則1項目1コミットで実装した。
転調の移動量は、ユーザーに確認して **3半音下(短3度下)** に確定した。「長3度下げ(4半音)」という言葉は採用せず、参照ループ Ab–Bb–Eb–Cm → F–G–C–Am の間隔に合わせた。

## 実測

条件は Phase 0 と同じ。固定seed 17 / 97 / 301 / 1009 / 8191、A短調(長調も測定)、mood=melancholic、count=5、4コード、各seed 40回。

### 通常生成(chorus、前セクション文脈なし)の変化

19スタイル × 長短調 = 38条件のうち、骨格種類数と平均点が変わったのは5条件のみ。残りは Phase 0 の値と一致した(`phase1-after.json` と `phase0-after.json`)。

| Style | Mode | 骨格 Phase 0 → Phase 1 | boutonnat平均 |
| --- | --- | ---: | ---: |
| cinematic | minor | 167 → 160 | 6.633 → 6.595 |
| finale | minor | 48 → 50 | 7.412 → 7.605 |
| neoclassical | minor | 49 → 49 | 8.455 → 8.454 |
| frenchPop | minor | 109 → 111 | 7.749 → 7.726 |
| kayokyoku | minor | 82 → 81 | 7.600 → 7.589 |

新ループ(回転を同値とする)の選抜後の出現率は cinematic 0.1% → 1.4%、finale 0.3% → 2.6%。「少数追加」の範囲に収まった。

### 各規則の選抜後の生存率(`phase1-rules.json`)

前セクションのループは `bVII-i-bIII-bVI`(cinematic の語彙内で、遷移表から自然には出にくい並び)。対照は文脈を渡さない同条件。

- **chorus の回転**: 回した並びの出現率(対照 → 文脈あり)は cinematic 4.3% → 20.6%、finale 8.2% → 30.3%、ethereal 1.7% → 25.2%。romanticDark・neoclassical・kayokyoku・sadcorePop などは 0% → 0%。このループ単体ではそれらのスタイルのシグネチャー(V / bII / #iv、iv など)を満たさず、選抜に残らない。シグネチャーを緩めない方針どおりの結果。
- **c-melody / bridge の使い回し**: cinematic で c-melody 3.1% → 10.5%、bridge 3.7% → 22.6%。同型として現れた進行には、そのスタイルの色彩和音が必ず入ることをテストで確認。
- **intro**(通常の未解決を主とし、反復とターンアラウンドが混ざる): V→i で終わる率は、ターンアラウンドを止めた場合(確率0)が romanticDark 24.0%、finale 16.2%、neoclassical 16.2%、cinematic 0%。確率8%では 33.1%、30.1%、19.9%、13.3% で、増加分は +9 / +14 / +4 / +13 ポイント。採点が完全終止を好むため、生成確率の8%より選抜後の増え方は大きい。「ときどき」の範囲として許容できると判断したが、多すぎるなら確率だけを下げれば調整できる。
- **決定的なメジャーV**: 19スタイル × 7セクション × 4/8コードの全条件で、1進行あたり最大1か所(sus を除く)。旋法・反復系(dorian / ritual / electronica / slowcore / tripHop / minimalism)は短調の全セクションで V の根音が出ない。

### plainDiatonic

`plainDiatonic` は変更していない。選抜後はスタイルを問わず 0%(装飾・スラッシュが付くため)で、選抜後の新ループも 0%。新ループの平均点は cinematic 6.79(全体 6.59)、finale 6.46(全体 7.61)。finale の新ループの平均点は低いが、plainDiatonic の減点ではなく、加点要素(完全終止・毒など)が少ないことによる。生の遷移(装飾前)の plainDiatonic 割合は `phase1-rules.json` にあるが、装飾前なので選抜後とは比べられない。
