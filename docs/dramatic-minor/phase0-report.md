選抜後の骨格履歴はseedの開始時のみクリアし、40回の呼び出し間では維持した。
同じseedを修正前後で使用。骨格は色彩・転回ベースを除いた度数列。

原指示では仕様と衝突する場合は報告して指示を待つ。次を後続実装前に確認する。

1. 「長3度下げ」は4半音だが、参照Aの Ab–Bb–Eb–Cm と例示 F–G–C–Am の間隔は3半音。どちらを `resolveKeyMove` の移動量として採用するか。説明・テスト・全12調の移動量を揃える必要がある。
2. romanticDarkの短調シグネチャーは V / bII / #iv のいずれかを必須とする。i-bVI-bVII-bIII単体の登録は既存テストと衝突するため、基準を維持したままcinematic / finaleへ追加する方針を提案する。
3. 現行の `plainDiatonic` はsus・maj7のある候補を減点対象にしていない。低得点は他の加点要素の不足も関係する。実測で必要性を判断し、採点式の大きな変更は先に報告する。

数値はこの条件下での方向性を示す。聴感の保証ではない。参照の度数・装飾の推定誤差は検証できず、音源は探していない。曲全体の評価・感情最適化は実装していない。
自分の差分に実在のアーティスト名・曲名・年代名を追加していない（既存APIのスコアキーは維持）。
